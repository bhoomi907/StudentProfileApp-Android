# Student Profile App – Android

An Android application built using Kotlin and XML that allows users to register student details, view their profiles, and manage saved student records.

# Features

- **Student Registration:** Enter a student's name and email address.
- **UI Widgets:** Uses EditText fields, Buttons, ImageViews, CheckBoxes, RadioButtons, Spinners, SeekBars, and RatingBars.
- **SQLite Database:** Stores student records locally on the device.
- **Three Screens:** Registration, Student Dashboard, and Saved Student Records.
- **Explicit Intents:** Navigate between activities and pass student information.
- **AlertDialog:** Display confirmation dialogs for actions such as deleting records.
- **Toast Messages:** Show feedback when an operation succeeds.
- **SharedPreferences:** Store small pieces of app data and preferences.

# Technologies Used

- Kotlin
- XML
- Android Studio
- SQLite
- Intents
- SharedPreferences

# How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the app on an Android emulator or a compatible Android device.
